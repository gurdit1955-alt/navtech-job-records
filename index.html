One-time setup
  1. Create a new Google Sheet, then Extensions ▸ Apps Script.
  2. Delete the sample code, paste the code copied above, and change "change-this-key" to your own secret.
  3. Run setup() once and approve permissions (creates the Designers tab and the 9:00 am reminder).
  4. Deploy ▸ New deployment ▸ Web app · Execute as: Me · Who has access: Anyone ▸ Deploy and authorise. If you are replacing an older script, use Deploy ▸ Manage deployments ▸ Edit ▸ New version.
  5. Paste the /exec link and the same secret key above, then press Save to Sheet now. (The link field is masked. To avoid pasting it on every device, set PRESET_SHEET_URL near the top of the page's script and the field disappears completely.)

Every change is saved to the Sheet within a couple of seconds and other devices pick it up within 2 minutes. If two people edit the same order, the newest edit wins. You can also edit rows directly in the Sheet. Deleting an order here marks it Deleted (Y) in the Sheet and removes it on other devices; the row stays in the Sheet as a record. Type Y in a row's "deleted" column to delete it from the Sheet side, or clear the Y to bring it back. Edits you type straight into the Sheet are picked up by the app on its next sync.
